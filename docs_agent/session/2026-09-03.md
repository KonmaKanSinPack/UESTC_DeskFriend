### 器官边界判定(已确认,ARCHITECTURE §四)

| 新增件 | 归属 | 理由 |
|---|---|---|
| `Qt.Tool` 窗口标志 / 托盘图标+菜单 / 右键菜单 | 皮(skin) | 呈现+输入物理层;主控不堆器官实现细节 |
| `quit_requested` 信号 | 皮广播 | 菜单项只 emit 不直接 app.quit(编排权不泄漏进皮肤) |
| `_shutdown()` 编排(顺序/幂等闩) | 脊髓(spine) | 跨器官流程:先脑(结算桥在飞请求)→再嘴→最后退出 |
| `mouth.stop()` | 嘴 | 器官命令(对称 speak/interrupt):打断在播+TTS close |
| `brain.stop()` | 脑 | 已存在,不动(幂等) |
| listen 停止 | 不显式做 | daemon 线程随进程终止,YAGNI |
| `quit_app` 回调注入 | 装配(main) | spine 零 Qt 红线靠它保住(同 reply_sink 模式) |

### 核心代码片段

```python
# skin.py —— 信号与菜单(器官只广播)
quit_requested = pyqtSignal()   # 托盘/右键「退出」→ 主控编排收摊

def _init_tray(self):
    self.tray = QSystemTrayIcon(self._tray_icon(), self)
    self.tray.setToolTip("桃桃 (UESTC_DeskFriend)")
    menu = QMenu(self)  # 父对象防 GC;triggered 带 checked 参数,用 lambda 桥到无参 emit
    menu.addAction("退出").triggered.connect(lambda: self.quit_requested.emit())
    self.tray.setContextMenu(menu)
    if QSystemTrayIcon.isSystemTrayAvailable():
        self.tray.show()   # 精简环境无托盘时跳过,右键菜单兜底

def contextMenuEvent(self, event):
    menu = QMenu(self)
    menu.addAction("退出").triggered.connect(lambda: self.quit_requested.emit())
    menu.exec_(event.globalPos())

# spine.py —— 编排(幂等闩,顺序=资源依赖序)
def __init__(self, ..., quit_app=None):
    self._quit_app = quit_app       # main 注入 app.quit;spine 不 import Qt
    self._shutting_down = False
    self.face.quit_requested.connect(self._on_quit_requested)

async def _shutdown(self):
    if self._shutting_down:
        return
    self._shutting_down = True
    await self.brain.stop()   # 桥结算在飞请求/观察循环取消(已有,幂等)
    await self.mouth.stop()   # 停在播朗读 + TTS 释放
    if self._quit_app:
        self._quit_app()

# mouth.py —— 器官命令
async def stop(self):
    await self.interrupt()    # 空闲时安全(后端有 if _busy 守卫);置 _gap_abort 关窗口
    await self.tts.close()    # 释放钩子(ABC 默认空操作)

# main.py —— 装配桥接(Qt↔spine 唯一交点)
spine = Spine(face=face, quit_app=app.quit)
```
