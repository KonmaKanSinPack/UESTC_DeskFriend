# 2026-09-04 会话:hotfix——重启后图片占位符毒化上下文致 API 500

## 问题(用户报错)

```
处理消息时出错了：Error code: 500 - {'error': {'message': "get file data from
'base64:[image omitted]' failed: failed to decode base64 data: illegal base64
data at input byte 0 ...", 'code': 'convert_request_failed'}}
```

## 根因链(已核实代码)

1. `look_at_screen` 工具消息带 base64 图进 openai 后端 context;
2. `memory.sanitize_message` 落库时把 `image_url.url` 替换为 `"[image omitted]"`
   占位符(防 pet.db 膨胀,Phase 5 设计);
3. **重启**后 `OpenAIBackend.__init__` 经 `memory.load_unsummarized()` 恢复上下文,
   占位符原样回到 `self.context`;
4. 此后每轮 `get_response` 把全量 context 发 API——网关把 `"[image omitted]"`
   当 base64 数据解码 → 500 convert_request_failed,**毒化重启后所有对话**。

## 修复(commit cc4211e)

在"库 → 运行时"还原边界加 `revive_message`(单点,memory.py):
- 判定:url 不以 `data:` 开头的图片段 = 非法(真实内存图片恒为 data: URL)
- 动作:换成 `{"type": "text", "text": "[历史截图，内容已省略]"}` 文本段
  (历史对 LLM 仍可读,不再有非法 image_url)
- `load_unsummarized` 返回前统一过这道转换;DB 存量数据(已带占位符)下次启动
  自动被修复,**无需迁移**

## 验证

- 新增 4 用例(占位符→文本段/原消息不改/data: 通过/纯文本通过/store 全链路
  roundtrip 无非法 image_url);全量 **200 passed**,ruff 全绿
- technical.md 数据结构小节同步(核心不变式补"恢复过 revive_message")

## 未完成/下一步

- 用户重启应用即生效;若仍复现 500 请把新报错发我(可能是别的消息形态)
- 沿用 PROGRESS 待办:openai 流式管道轮(首选)/Live2D 轮/动画渲染改造/P1/AEC

# 2026-09-04 会话(第三轮):PSD 直驱渲染器——桃桃动起来(不依赖 Cubism)

## Plan + Spec(路线已经用户确认)

### 背景

用户用 See-through 把桃桃立绘拆成 16 层 PSD(768×768,眼睛四件套/前后发/四肢齐全,
但左右未分离/遮挡未补/嘴仅 13×8)。Cubism Editor 绑定是 GUI 创作无法代做,
用户选择** PSD 直驱**:程序化修 PSD + 自写渲染器,零 Cubism 依赖;真 Live2D 留作
后续升级(同一份素材,渲染器缝可换)。

### 设计

```
tools/prepare_psd.py(一次性工具,入库可复用)
  输入 seethrough PSD → ①左右分离(列间隙法:eyewhite/irides/eyelash/eyebrow/
  handwear/footwear/legwear 各拆 L/R)②边缘扩展 ~15px(迭代膨胀+最近色填充,
  防动起来露洞)③导出 assets/live2d/taotao/{层名}.png + manifest.json
  (canvas/层列表[name,file,x,y]/底层→顶层绘制序)

psd_renderer.py(新,皮的渲染细节,不认器官/大脑)
  PsdRenderer(QWidget):paintEvent 按序画层,各层带动画变换——
  - 眨眼:eyelash L/R 独立 scaleY(随机 2-6s 间隔,~120ms 一眨)——"活感"大头
  - 视线跟随:irides L/R 在眼窝内 ±4px 追鼠标(QCursor 全局位置,纯读)
  - 口型:talking 态 mouth scaleY 正弦开合(便宜但有效,无需画口型)
  - 呼吸:躯干层微缩放;发丝轻摆:hair 层微旋转;thinking:头部层小幅度摆
  - set_anim_state 语义照旧(idle/thinking/talking 映射动作组合)
skin:SPRITE 指向 manifest.json → 装配 PsdRenderer;.png/.gif → 原 QLabel 路径
```

### 边界与决策

- 器官边界:渲染器是皮内部细节(ps`d_renderer 不 import 器官/大脑;鼠标位置
  是纯输入读取,同耳读麦克风);talking 口型由既有 set_anim_state("talking")
  驱动,不新增跨器官依赖
- 纯函数抽离可测:split_lr(列间隙切分)、edge_extend(膨胀+最近色)、
  blink/eye-track/mouth 的数学(钳制/调度)
- psd-tools 依赖仅 tools 用(入库以便复现);运行时只吃 PNG+manifest
- 眨眼/视线常开(活感),其余按状态
